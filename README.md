# E-Commerce Sales Dashboard

Sample portfolio project analyzing the Olist Brazilian E-Commerce public dataset (2016–2018) 
to demonstrate dashboard design and KPI reporting for online retail businesses.

## Business Question
How is the business performing month over month, which product categories drive 
the most revenue, and is delivery performance affecting how customers rate their 
experience? This dashboard gives a store owner a fast, at-a-glance answer to all three.

## Key Metrics
- Total Revenue: $13.22M (delivered orders only)
- Total Orders: 96K
- Average Order Value: $137.04
- Average Review Score: 4.09 / 5
- On-Time Delivery Rate: 89.15%

## Key Insight
Late and non-delivered orders show significantly lower review scores (2.57 and 1.76) 
compared to on-time orders (4.29) — logistics reliability directly drives customer satisfaction.

## Tools Used
Power BI, DAX, Power Query

## Data Source
https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

## Notes
- Values shown in USD format for portfolio purposes; source data is in Brazilian Real (BRL).
- Revenue trend shows a drop-off in the final month, a known limitation of this dataset's 
  data collection period rather than a real business decline.
